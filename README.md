## Setup

Make sure to install dependencies:

```bash
# yarn
yarn install

# bun
bun install
```

## Development Server

Start the development server on `http://localhost:3000`:

```bash
# yarn
yarn dev

# bun
bun run dev
```

## Production

Build the application for production:

```bash

# yarn
yarn build

# bun
bun run build
```

Locally preview production build:

```bash
# yarn
yarn preview

# bun
bun run preview
```
